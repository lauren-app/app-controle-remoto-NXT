# 📱 controle-remoto-NXT

 O Controle Remoto de NXT é um aplicativo criado no App Inventor para operar robôs LEGO Mindstorms NXT via Bluetooth. Ele possui uma interface intuitiva com um botão prático para selecionar e parear o dispositivo, além de controles direcionais de movimentação contínua, que mantêm o carrinho andando até que o botão de parar seja pressionado. Embora tenha sido feito inicialmente para estudantes de desenvolvimento mobile, o app é ideal para qualquer pessoa que queira testar projetos com o LEGO NXT.  
 
---

## 🎯 Objetivo
O controle remoto NXT serve para pilotar os robôs Lego Mindstorms à distância, acionando seus motores em tempo real via conexão Bluetooth.
Ele resolve a necessidade de criar programações completas apenas para testar se as peças, engrenagens e mecanismos físicos foram montados corretamente.

## ✨ Funcionalidades
- Funcionalidade 1 ( Mover-se para frente)
- Funcionalidade 2 ( trás)
- Funcionalidade 3 ( Esquerda)
- Funcionalidade 4 ( Direita)
- Funcionalidade 5 ( Movimentação contínua: Sistema onde o robô mantém o movimento até que o botão "parar" seja acionado)
- Funcionalidade 6 ( Conectar/desconectar do robô via Bluetooth)
## ️ Tecnologias Utilizadas
- **MIT App Inventor** (Desenvolvimento em blocos)
- **GitHub** (Hospedagem do projeto)

## 📂 Como testar este aplicativo?
1. Baixe o arquivo `.aia` disponível neste repositório.
2. Acesse o [MIT App Inventor](http://ai2.appinventor.mit.edu/).
3. Clique em **Projetos > Importar projeto (.aia) do meu computador**.
4. Selecione o arquivo baixado para visualizar e testar o código!
